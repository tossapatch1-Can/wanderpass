Copy API keys 3 ตัว

หลัง project พร้อม → ไปที่ Project Settings (⚙️) → API ในเมนูซ้าย. คุณจะเจอ 3 ตัวที่ต้อง copy:

1Project URL — ขึ้นต้นด้วย https://xxxx.supabase.co
2anon public — key สำหรับ browser (เห็นได้ ไม่เป็นไร)
3service_role secret — key สำหรับ server (ห้ามใส่ใน code ที่ user เห็น)
📋 Tip: เปิด .env.local ในอีก tab รอไว้ — copy ทีละตัวมาวาง

กด Run แล้วทำซ้ำกับ seed.sql

หลัง paste schema.sql → กด Run (หรือ ⌘+Enter) → จะเห็น Success. No rows returned

1ถ้าเห็น "Success" สีเขียว = ตารางทั้ง 3 ถูกสร้างแล้ว ✨
2กด + New query อีกครั้ง
3เปิด supabase/seed.sql → copy ทั้งหมด → paste → Run
4คราวนี้จะเห็น Success. 8 rows returned = 8 destinations ถูก insert ✅
🐛 ถ้าเจอ error: มักเป็น "relation already exists" — ไม่เป็นไร script เขียนเป็น if not exists รัน safe

6

เปิดให้ Auth ใช้ localhost

ตอน user คลิก magic link จาก email → Supabase ต้อง redirect กลับมาที่ app. ต้องบอกล่วงหน้าว่า URL ไหนใช้ได้

1เมนูซ้าย → Authentication → URL Configuration
2ที่ Site URL ใส่: http://localhost:3200
3ที่ Redirect URLs add: http://localhost:3200/**
4ทีหลังตอน deploy Vercel → add Vercel URL ด้วย เช่น https://wanderpass.vercel.app/**
⚠️ ห้ามลืม step นี้ ไม่งั้นนักเรียนจะเจอ error ตอน login
supabase.com/dashboard/project/.../auth/url-configuration
